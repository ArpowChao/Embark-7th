# 第七屆專題籌備委員會：LINE 官方聯絡群組整合與組別職責校正 設計規格

## 1. 概述 (Overview)
為確保第七屆專題籌備委員會招募流程順暢，本設計涵蓋兩大核心更新：
1. **LINE 官方聯絡群組深度整合**：落實「報名就請加入」原則，在報名成功彈窗與表單流程中醒目引導同學加入社群（包含 QR Code、跳轉按鈕、複製連結），方便委員會後續通知面試時段、公布名單及進行後續聯絡。
2. **組織架構與組別職責校正**：將原本的「文書組」正式更名為「文宣組」，並依據籌委會真實分工精確修正「行政組」、「活動組」與「文宣組」之職責描述與標籤。

* 在「確認送出報名表」按鈕上方放置重要提示卡：

#### 3. 「查詢 / 修改已填資料」頁面
* 同學查詢時若先前未加入群組，此區塊亦提供一鍵加入與掃碼入口，避免遺漏。

## 3. 驗證計畫 (Verification Plan)
1. **功能驗證**：
   - 點擊 LINE 加入按鈕可正確開啟 LINE OpenChat 邀請頁面。
   - 點擊複製連結按鈕可正確複製完整網址並彈出 Toast 提示。
   - QR Code 圖片載入清晰、比例正常。
2. **表單與志願連動驗證**：
   - 第一志願選擇「行政」時，自動鎖定為「組長」並停用「組員」。
   - 第一志願選擇「文宣」、「活動」等組別時，可正常自由選擇「組長」或「組員」。
   - 次要志願（其他組別多選）正確過濾掉第一志願，且顯示「文宣組」而非舊的文書組。
3. **響應式驗證**：
   - 在電腦版與手機版螢幕寬度下，彈窗與 QR Code 均能完美排版無破版。
