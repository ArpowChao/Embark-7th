## ✨ 核心特色與防呆規則

1. **八大組別完整劃分**：
   - 👑 總召、🌟 副總召、📋 行政（會議記錄與公假聯絡）、📢 文宣（宣傳推廣與IG經營）、🎉 活動（主持拍片與活動設計）、🎨 美宣、📷 攝媒、💻 資訊
2. **智慧職位防呆**：
   - 當第一志願選擇 **「總召」**、**「副總召」** 或 **「行政」** 時，系統將自動鎖定為 **「組長」**，並**禁用與灰色淡化「組員」選項**，同時顯示溫馨說明。
   - 其他組別（文宣、活動、美宣、攝媒、資訊）則可自由選擇「組長」或「組員」。
3. **滿版送出回饋與 LINE 官方聯絡群組引導**：
   - 點擊送出時具備 Loading 載入動態，送出成功後彈出溫馨確認卡片並發射繽紛彩帶特效（Canvas Confetti）。
   - 彈窗與全站整合「7th 專題籌備委員會」官方 LINE 社群（支援一鍵加入、QR Code 手機掃描、一鍵複製連結），確保同學報名後能第一時間加入群組，以利後續面試與籌備聯絡通知！
4. **隨時查詢與修改資料**：
   - 已報名的同學只要切換到「🔍 查詢 / 修改已填資料」，選取「班級 (201~211)」，並輸入「座號、姓名」，系統便會自動將先前填寫的資料回填進表單。
   - 修改完成後點擊「💾 儲存修改內容」，Google Sheet 資料庫將自動就地更新該筆資料，不會重複產生多餘列。
5. **10~11月培訓期與面試時段調查**：
   - 培訓僅安排於「平日中午」與「自主學習時間」，絕不佔用週末假日或放學過多時間。
   - 支援平日中午、自主學習時間與放學後等多選時段，各自獨立統計，方便籌劃。

## 🔒 學生個資保護與名冊防呆機制（零個資外洩架構）

本系統為嚴格遵循我國**《個人資料保護法》**與校園資安規範，採取**零個資外洩（Zero-Leakage）後端驗證架構**：
1. **前端完全不存放學生真實姓名**：
   - 前端網頁與公開程式碼庫中**絕不包含任何學生姓名或名冊清單**，徹底避免遭有心人士藉由 F12 開發者工具或下載靜態原始碼爬取全校名冊。
   - 專案已配置 [`.gitignore`](file:///f:/Program/7th/.gitignore)，嚴格禁止 `*.xlsx`、`*.csv` 與任何名單檔案被推送至公開 Git 倉庫。
2. **私有雲端伺服器權威核驗**：
   - 學生名冊僅存放於學校管理者**私有的 Google 試算表**中（工作表名稱：`學生名冊`），外部完全無法查看試算表內容。
   - 學生在前端輸入姓名後，系統透過安全 API 進行核驗（API **僅回傳比對成功或失敗**，絕不向外界洩漏任何他人姓名）。
   - 報名送出時，GAS 後端進行嚴格查核，若班級、座號與姓名不吻合，後端直接拒絕寫入並回傳 `❌ 名冊查無此人`。

### 📋 如何在私有 Google 試算表中啟用名冊核驗？
1. 打開管理者專屬的 [Google 試算表](https://docs.google.com/spreadsheets/d/1VmMxK6BNoiq8KQL0xqWY3jexgeuh8yPjPSQXgBQ_e-U/edit?usp=sharing)。
2. 在左下角點擊「➕ 新增工作表」，並將工作表命名為 **`學生名冊`**（或在 Apps Script 執行 `setupRosterSheetTemplate` 函式自動建置）。
3. 在 `學生名冊` 工作表中貼入三欄資料：
   - **A 欄**：`班級`（例如：101, 102 ... 212）
   - **B 欄**：`座號`（例如：1, 2, 3 ...）
   - **C 欄**：`姓名`（例如：王小明）
4. 完成後，所有報名與查詢將自動啟用精準的「查無此人」防呆保護！
